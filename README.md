PySpark Data Cleaning Pipeline
Project Overview

This project demonstrates a simple ETL (Extract, Transform, Load) pipeline using PySpark. The pipeline reads raw CSV data, performs data cleaning and transformation operations, and writes the cleaned dataset to an output directory. The purpose of this project is to simulate a real-world data engineering workflow where raw data is processed into a structured and usable format.

Objective

The objective of this project is to:

Read raw data from a CSV file.

Perform data cleaning and transformation using PySpark.

Handle missing values.

Convert data types for better processing.

Remove invalid records.

Store the cleaned dataset for downstream analytics.

Apache Spark (PySpark)
